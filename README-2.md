# Student Management App - Node.js + MySQL

This version uses:
HTML/CSS/JavaScript -> Node.js + Express -> MySQL

## Requirements
- Node.js 18+
- MySQL Server

## Setup
1. Run `database.sql` in MySQL.
2. Open `server.js` and change DB_PASSWORD to your MySQL password.
3. Open a terminal in this project folder.
4. Run:
   npm install
   npm start
5. Open:
   http://localhost:3000

Features:
- Add student
- View students
- Update student
- Delete student

Note: This Node.js version does not require Java Servlet or JDBC. Node.js uses the `mysql2` package to communicate with MySQL.
